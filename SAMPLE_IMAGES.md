# PixelLab Digital Image Processing Studio – Sample Benchmark Dataset

This document records the provenance, optical characteristics, mathematical noise profile, and licensing terms of the built-in sample images provided with PixelLab.

---

## 1. Dataset Overview

All sample images are generated and packaged locally as reproducible, high-fidelity synthetic computer vision benchmark targets. No external web URLs or third-party image hosts are used at runtime.

| Identifier | Category | Dimensions | Color Mode | Primary Purpose / Feature |
| :--- | :--- | :--- | :--- | :--- |
| `landscape` | Natural Scene / Landscape | 512 × 512 | RGB (3-Channel) | Multi-frequency gradient skies, mountain ridges, and organic textures. |
| `coins_objects` | Industrial Objects / Coins | 512 × 512 | RGB (3-Channel) | Specular metallic highlights, circular boundaries, and touch points. |
| `portrait` | Human Subject / Portrait | 512 × 512 | RGB (3-Channel) | Soft skin tones, gradual shading, and distinct silhouette contours. |
| `document_text` | Text & Document | 512 × 512 | Grayscale (1-Channel) | High-contrast character strokes, typography, and tabular lines. |
| `textured_fabric` | High-Frequency Texture | 512 × 512 | RGB (3-Channel) | Dense repetitive cross-weave pattern with high spatial frequency. |

## 2. Noise Generation Model

To enable deterministic, reproducible quantitative quality evaluation ($MSE$, $PSNR$, $SSIM$), the noisy versions are generated by adding zero-mean Additive White Gaussian Noise (AWGN) with a fixed pseudo-random seed ($\text{seed} = 42$):

$$I_{\text{noisy}}(x, y) = \text{clip}\Big(I_{\text{clean}}(x, y) + \mathcal{N}(0, \sigma_n^2), \, 0, \, 255\Big)$$

- **Standard Deviation ($\sigma_n$)**: $25.0$ intensity levels.
- **Random Seed**: $42$ (reproducible across platforms).
- **Quantization**: 8-bit unsigned integer ($0 \le I \le 255$).

---

## 3. Pairing Specification

Every sample is distributed as a matched pair:
1. `clean_<id>.png`: Uncorrupted ground-truth reference matrix.
2. `noisy_<id>.png`: Degraded sensor simulation matrix used as the primary input.

When a sample is loaded in PixelLab:
- `noisy_<id>.png` is loaded into the input canvas.
- `clean_<id>.png` is automatically supplied as the ground-truth reference, unlocking true reference-based $MSE$, $PSNR$ (in dB), and $SSIM$ calculations.
